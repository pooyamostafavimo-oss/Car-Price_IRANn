# ربات قیمت روز خودرو (ایران جیب → تلگرام)

هر روز ساعت ۱۱:۰۰ به وقت تهران، این ورک‌فلو گیت‌هاب به‌صورت خودکار:
1. قیمت‌های روز خودرو را از سایت [ایران جیب](https://www.iranjib.ir) می‌خواند.
2. یک پیام (یا چند پیام، در صورت طولانی بودن) در کانال/گروه تلگرام شما ارسال می‌کند.
3. پیام جدید را **پین** می‌کند و پیام(های) پین‌شده‌ی روز قبل را **آن‌پین** می‌کند.

## پیش‌نیازها

### ۱. ساخت ربات تلگرام
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید.
2. دستور `/newbot` را بزنید و نام و یوزرنیم دلخواه را بدهید.
3. توکنی که می‌دهد را ذخیره کنید (چیزی شبیه `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`).

### ۲. اضافه کردن ربات به کانال/گروه
- ربات را به کانال یا گروه موردنظر اضافه کنید و آن را **ادمین** کنید (با دسترسی «ارسال پیام» و «پین کردن پیام»).

### ۳. پیدا کردن chat_id
راحت‌ترین راه:
1. یک پیام تستی در کانال/گروه بفرستید.
2. این آدرس را در مرورگر باز کنید (به‌جای `<TOKEN>` توکن ربات را بگذارید):
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
3. در خروجی JSON دنبال `"chat":{"id": ...}` بگردید. برای کانال/گروه معمولاً عددی منفی است، مثلاً `-1001234567890`.
   (اگر کانال عمومی است، می‌توانید مستقیماً از `@your_channel_username` هم به‌عنوان chat_id استفاده کنید.)

## راه‌اندازی روی گیت‌هاب

1. یک ریپازیتوری جدید بسازید و تمام فایل‌های این پروژه را در آن قرار دهید (یا این فولدر را مستقیماً push کنید).
2. به مسیر **Settings → Secrets and variables → Actions** بروید و دو Secret زیر را اضافه کنید:
   - `TELEGRAM_BOT_TOKEN` → توکن ربات
   - `TELEGRAM_CHAT_ID` → شناسه‌ی چت/کانال
3. به تب **Actions** بروید، ورک‌فلو `Daily Car Price Update` را پیدا کنید و یک‌بار به‌صورت دستی (`Run workflow`) اجرا کنید تا مطمئن شوید همه‌چیز درست کار می‌کند.
4. از این پس، هر روز ساعت ۱۱:۰۰ به وقت تهران به‌طور خودکار اجرا می‌شود.

## نکات مهم

- **زمان‌بندی cron در GitHub Actions بر مبنای UTC است.** چون ایران در حال حاضر تمام سال UTC+3:30 است (تغییر ساعت تابستانی از سال ۱۴۰۱ لغو شده)، مقدار `30 7 * * *` معادل ساعت ۱۱:۰۰ تهران است. اگر این موضوع در آینده تغییر کند، باید مقدار cron را در فایل `.github/workflows/daily-price-update.yml` به‌روزرسانی کنید.
- **زمان‌بندی GitHub Actions تضمین‌شده و دقیق‌به‌ثانیه نیست**؛ ممکن است اجرا با چند دقیقه تأخیر شروع شود (این محدودیت خود GitHub است).
- فایل `state.json` شناسه‌ی آخرین پیام(های) ارسالی را نگه می‌دارد تا اسکریپت بداند کدام پیام(ها) را باید آن‌پین کند. این فایل به‌صورت خودکار توسط خود ورک‌فلو کامیت می‌شود؛ آن را دستی ویرایش نکنید.
- اگر ساختار HTML سایت ایران جیب در آینده تغییر کند، ممکن است لازم باشد تابع `parse_groups` در `scripts/post_prices.py` را متناسب با ساختار جدید به‌روزرسانی کنید. برای دیباگ، می‌توانید اسکریپت را لوکال اجرا کرده و خروجی `groups` را چاپ کنید.
- استفاده از داده‌های این سایت را با توجه به قوانین و شرایط استفاده (ToS) خود سایت ایران جیب انجام دهید؛ ذکر منبع در پیام‌ها رعایت شده است.

## اجرای لوکال (برای تست)

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="توکن‌ شما"
export TELEGRAM_CHAT_ID="chat id شما"
python scripts/post_prices.py
```
